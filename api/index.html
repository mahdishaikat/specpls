    API reference¶

    Model¶

    Bases: RegressorMixin, BaseEstimator

    Single-response PLS calibration for spectroscopic data.

    Wraps preprocessing and :class:sklearn.cross_decomposition.PLSRegression in one scikit-learn estimator and adds what a chemometric workflow needs: automatic choice of latent variables from RMSECV, Hotelling's T2 and Q-residual diagnostics, VIP scores, and safe save/load for deployment.

    Preprocessing is fitted inside every cross-validation fold, so RMSECV is not optimistically biased by data-dependent steps such as MSC.

    Parameters:

    Name Type Description Default
    preprocessing str, list of transformers, Pipeline or None

    Preprocessing applied before PLS. A string such as "savgol:15:2:1,snv" is parsed with :func:specpls.preprocessing.build_preprocessing.

    		 None
    n_components int or 'auto'

    Number of latent variables. "auto" picks it from RMSECV using lv_rule.

    		 "auto"
    max_components int

    Largest number of LVs tried when n_components="auto".

    		 10
    cv (int, str or splitter)

    Cross-validation scheme, see :func:specpls.validation.make_cv. Use "batch" together with groups in :meth:fit to hold out whole bioreactor runs.

    		 10
    lv_rule ('parsimonious', 'min', 'first_min')

    Rule for choosing LVs from the RMSECV curve.

    		 "parsimonious"
    lv_tolerance float

    Relative tolerance for the parsimonious rule.

    		 0.02
    regions list of (low, high)

    Wavenumber regions to keep, e.g. [(400, 1800)]. Applied before preprocessing. Requires wavenumbers in :meth:fit.

    		 None
    scale bool

    Autoscale variables inside PLS. Spectra are normally only mean-centred, so the default is False (unlike scikit-learn).

    		 False
    max_cv_ratio float

    Over-fitting guard for automatic LV selection: only LVs with RMSECV / RMSEC <= max_cv_ratio are eligible (1.2 = RMSECV at most 20 % above RMSEC). A warning is issued if no LV qualifies.

    		 None

    Attributes:

    Name Type Description
    n_components_ int

    Number of LVs in the final model.
    rmsecv_curve_ ndarray

    RMSECV for 1..max_components LVs (None if LVs were fixed).
    rmsec_curve_ ndarray

    RMSEC for the same LVs (None if LVs were fixed).
    ratio_ok_ bool

    False if max_cv_ratio was set and no LV satisfied it.
    cv_predictions_ ndarray

    Cross-validated predictions for the training samples.
    pipeline_ Pipeline

    The fitted region selection + preprocessing + PLS pipeline.
    calibration_ dict

    Figures of merit for calibration (RMSEC) and cross-validation (RMSECV).
    wavenumbers_ ndarray or None

    Wavenumber axis the model was trained on.
    target_name_ str or None

    Name of the predicted variable, e.g. "glucose".

    Examples:

    >>> from specpls import PLSModel
>>> from specpls.datasets import make_synthetic_cell_culture
>>> data = make_synthetic_cell_culture(random_state=0)
>>> model = PLSModel(preprocessing="savgol:15:2:1,snv", max_components=8)
>>> model = model.fit(data.X, data.target("glucose"),
...                   wavenumbers=data.wavenumbers, target_name="glucose")
>>> model.n_components_ > 0
True

    predict(X, *, wavenumbers=None) ¶

    Predict the response for new spectra.

    If wavenumbers is given, it is checked against the calibration axis, which guards against applying a model to spectra from a different instrument set-up.

    evaluate(X, y, *, wavenumbers=None) ¶

    Figures of merit on an independent test set (RMSEP, R2, bias, ...).

    summary(X_test=None, y_test=None) ¶

    One-row summary in the style of a publication table.

    Returns LVs, RMSEC, R2 cal, RMSECV, R2 CV and, if a test set is given, RMSEP and R2 test.

    transform(X) ¶

    Preprocessed spectra (input to PLS) for inspection or plotting.

    scores(X) ¶

    Latent-variable scores, shape (n_samples, n_components_).

    hotelling_t2(X) ¶

    Hotelling's T2 for each sample (distance within the model plane).

    q_residuals(X) ¶

    Q residuals (squared prediction error, SPE) for each sample.

    t2_limit(confidence=0.95) ¶

    T2 control limit based on the F distribution.

    A (n-1) / (n-A) * F(confidence; A, n-A) with A LVs and n calibration samples.

    q_limit(confidence=0.95) ¶

    Q control limit using Box's scaled chi-square approximation.

    outliers(X, confidence=0.95) ¶

    T2, Q and boolean flags for samples outside the control limits.

    vip() ¶

    Variable Importance in Projection for each (selected) wavenumber.

    Variables with VIP > 1 are conventionally considered important. The mean of VIP**2 over all variables equals 1.

    save(path) ¶

    Save the fitted model with metadata to a .joblib file.

    Load a model saved with :meth:PLSModel.save.

    Warns if it was created with a different scikit-learn version, because pickled estimators are not guaranteed to be compatible across versions.

    Only load files from sources you trust: joblib files can execute code.

    Preprocessing¶

    Spectral preprocessing transformers.

    Every transformer follows the scikit-learn fit/transform API, so they can be chained in a :class:sklearn.pipeline.Pipeline and are re-fitted inside each cross-validation fold. That matters for data-dependent methods such as MSC, whose reference spectrum must come from the training data only.

    Spectra are always arranged as (n_samples, n_wavenumbers).

    PREPROCESSORS = {'snv': (SNV, ()), 'msc': (MSC, ()), 'savgol': (SavitzkyGolay, ('window_length', 'polyorder', 'deriv')), 'sg': (SavitzkyGolay, ('window_length', 'polyorder', 'deriv')), 'detrend': (Detrend, ('order',)), 'asls': (AsLSBaseline, ('lam', 'p', 'n_iter')), 'epo': (EPO, ('n_components',))} module-attribute ¶

    Short names accepted by :func:build_preprocessing and the CLI.

    SNV ¶

    Bases: _SpectralTransformer

    Standard Normal Variate: centre and scale each spectrum individually.

    Removes multiplicative scatter and path-length effects. Stateless: fitting only records the number of wavenumbers.

    MSC ¶

    Bases: _SpectralTransformer

    Multiplicative Scatter Correction.

    Each spectrum x is regressed on a reference spectrum r (x = a + b * r) and corrected as (x - a) / b.

    Parameters:

    Name Type Description Default
    reference array-like of shape (n_wavenumbers,)

    Fixed reference spectrum. If None (default), the mean spectrum of the training data is used.

    		 None

    AsLSBaseline ¶

    Bases: _SpectralTransformer

    Asymmetric Least Squares baseline removal (Eilers & Boelens, 2005).

    Fits a smooth baseline that stays below the Raman peaks, which suits broad fluorescence backgrounds.

    Parameters:

    Name Type Description Default

    Smoothness penalty. Larger values give a stiffer baseline.

    		 1e5
    p float

    Asymmetry weight for points above the baseline (0 < p < 1).

    		 0.01
    n_iter int

    Number of reweighting iterations.

    		 10

    EPO ¶

    Bases: _SpectralTransformer

    External Parameter Orthogonalisation (Roger et al., 2003).

    Estimates the directions of unwanted spectral variation ("clutter") and projects every spectrum onto the space orthogonal to them: X_epo = X (I - V V'), where V holds the first n_components right singular vectors of the clutter matrix D.

    How D is built:

    • clutter given: those spectra are used as D directly, e.g. differences between the same sample measured at two temperatures or in two vessels.
    • otherwise (default, "y-gradient", as in PLS_Toolbox GLSW/EPO): the calibration spectra are sorted by y and D contains differences between neighbouring samples. Samples with nearly the same analyte concentration should have nearly the same spectrum, so what differs between them is interference (fluorescence, cell density, matrix).

    y is required in fit for the y-gradient mode. Inside :class:~specpls.model.PLSModel it is fitted on the training folds only.

    Parameters:

    Name Type Description Default
    n_components int

    Number of clutter directions removed. Choose by RMSECV; too many removes analyte signal.

    		 2
    clutter array-like of shape (n_clutter, n_wavenumbers)

    Explicit clutter (difference) spectra, already preprocessed the same way as X.

    		 None

    Validation¶

    Figures of merit and cross-validation schemes for calibration models.

    VenetianBlinds ¶

    Bases: BaseCrossValidator

    Venetian-blinds cross-validation (sample i goes to fold i % k).

    This is the default scheme in many chemometrics packages (e.g. "vet" in PLS_Toolbox). It assumes samples are ordered, e.g. by time or concentration, so that every fold spans the whole range.

    Parameters:

    Name Type Description Default
    n_splits int

    Number of folds.

    		 10

    LVSelection dataclass ¶

    Result of latent-variable selection.

    ratio_ok is False when a max_ratio was requested but no number of LVs satisfied it; the LV count with the smallest RMSECV/RMSEC ratio is returned in that case.

    rmse(y_true, y_pred) ¶

    Root mean square error. Used for RMSEC, RMSECV and RMSEP.

    r2(y_true, y_pred) ¶

    Coefficient of determination, 1 - SS_res / SS_tot.

    bias(y_true, y_pred) ¶

    Mean of y_pred - y_true. Positive means the model over-predicts.

    sep(y_true, y_pred) ¶

    Standard error of prediction, corrected for bias.

    RMSEP**2 ~= SEP**2 + bias**2 (exact up to the n / n-1 factor).

    rpd(y_true, y_pred) ¶

    Ratio of performance to deviation: SD(y_true) / SEP.

    regression_metrics(y_true, y_pred) ¶

    All figures of merit as a dict: rmse, r2, bias, sep, rpd, n.

    make_cv(cv=10, groups=None) ¶

    Turn a short description into a scikit-learn CV splitter.

    Parameters:

    Name Type Description Default
    cv (int, str or splitter)
    • int - venetian blinds with that many folds
    • "venetian:k" - venetian blinds, k folds
    • "kfold:k" - contiguous blocks, k folds (no shuffling)
    • "loo" - leave-one-out
    • "batch" / "group" - leave-one-group-out; requires groups. Use this for bioprocess data so that all samples from one batch or bioreactor run are held out together.
    • any object with a split method is returned unchanged.
    		 10
    groups array - like

    Group labels (e.g. batch IDs). Required for "batch".

    		 None

    select_n_components(rmsecv, rule='parsimonious', tolerance=0.02, rmsec=None, max_ratio=None) ¶

    Pick the number of latent variables from an RMSECV curve.

    Parameters:

    Name Type Description Default
    rmsecv array - like

    RMSECV for 1, 2, ..., A latent variables.

    		 required
    rule ('parsimonious', 'min', 'first_min')
    • "min" - global minimum. Tends to over-fit on small data sets.
    • "first_min" - first local minimum of the curve.
    • "parsimonious" (default) - fewest LVs whose RMSECV is within tolerance (relative) of the global minimum. Trades a negligible loss of accuracy for a simpler, more robust model.
    		 "parsimonious"
    tolerance float

    Relative tolerance for the parsimonious rule (0.02 = 2 %).

    		 0.02
    rmsec array - like

    RMSEC for the same LVs. Required with max_ratio.

    		 None
    max_ratio float

    Over-fitting guard: only LVs with RMSECV / RMSEC <= max_ratio are eligible (e.g. 1.2 means RMSECV may exceed RMSEC by at most 20 %). The rule is then applied among the eligible LVs.

    		 None

    Returns:

    Type Description
    LVSelection

    Plotting¶

    Standard diagnostic plots for a fitted :class:~specpls.model.PLSModel.

    Requires matplotlib (pip install "specpls[plot]"). Every function accepts an optional ax and returns the axes, so plots can be combined in figures.

    plot_spectra(wavenumbers, X, color_by=None, ax=None, cmap='viridis', label=None) ¶

    Overlay spectra, optionally coloured by a reference value.

    plot_rmsecv(model, ax=None) ¶

    RMSECV versus number of latent variables, with the chosen LV marked.

    plot_predicted_vs_measured(model, y_cal, X_test=None, y_test=None, ax=None, units='') ¶

    Cross-validated (and optional test-set) predictions against reference.

    plot_vip(model, ax=None, threshold=1.0) ¶

    VIP scores across the spectrum with the VIP = 1 threshold.

    plot_t2_q(model, X, ax=None, confidence=0.95, labels=None, X_test=None, test_labels=None) ¶

    Hotelling's T2 versus Q residuals with control limits.

    X is plotted as calibration (blue circles); an optional X_test is added as test samples (orange diamonds). Samples outside a limit are labelled when labels are given.

    plot_scores(model, X, y=None, X_test=None, y_test=None, components=(1, 2), ax=None) ¶

    Score plot.

    With two or more LVs: LV components[0] versus LV components[1]. With a one-LV model: LV1 score for each sample (sample order on x). Points are calibration (blue circles) and test (orange diamonds).

    plot_loadings(model, components=None, ax=None) ¶

    X-loadings of the selected LVs across the spectrum.

    plot_overview(model, X_cal, y_cal, X_test=None, y_test=None, units='') ¶

    Four-panel figure: RMSECV, predicted vs measured, VIP, T2-Q.

    plot_ipls(result, X=None, ax=None) ¶

    Classic iPLS plot: RMSECV of each interval, selected intervals highlighted.

    The dashed line is the all-variable model; the grey curve (if X is given) is the mean spectrum for orientation.
